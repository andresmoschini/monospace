READ THIS BEFORE TRUSTING THE FIRST NUMBER

The comparison that produced "-80, tuirealm saves lines" was against
q6_plain.rs, which draws the same picture and does nothing else. It was wrong,
and wrong in the direction that flattered the framework: the ratatui side was
missing the event loop, the Msg enum, the update function and the mouse
hit-test that the tuirealm side had. Counting both at the same functionality
turns +107 into +48.

The live loop added 27 lines to the tuirealm side, which is why the earlier
figure was 124 and this one is 151. The earlier 124 was a headless print-only
version — see the commit on this branch.

WHAT NONE OF THIS COUNTS

Lines are not the argument for tuirealm either way. chrome.rs is 360 because it
has per-component types and real hit-testing, and the same file written against
plain ratatui would be a different 360 rather than a smaller one. The argument
for the framework is the routing model; the argument against it is in
reports/geometry.md.
