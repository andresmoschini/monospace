[ 01 / WHAT IS IT ]

Portable diagrams as plain text

Diagrams belong where engineers read and write: alongside code, commit messages, and design discussions.

# What is Monospace?

Monospace is a toolkit and suite of applications written in Rust for designing diagrams rendered entirely in monospaced ASCII and Unicode box-drawing characters. It includes a portable core engine, a lightning-fast command-line interface, and an interactive terminal editor.

> Why ASCII and plain text?

Binary image assets and proprietary canvas formats do not blend well with version control. ASCII diagrams live in plain text: diff them cleanly with git diff, embed them in Markdown fences, paste them into pull request summaries, or read them directly in terminal logs without specialized viewers.

Shapes compose naturally at shared cells: intersecting lines form true junctions, adjacent boxes cleanly share borders, and connectors calculate their own routes.

* Spec-Driven & Honest Rust

This project is an intentional exercise in Spec-Driven Development and principled Rust architecture. Every feature starts with a concrete issue and an agreed specification before code is written. Domain logic is strictly isolated from terminal handling, cross-compiling seamlessly to WebAssembly.

Explore the methodology in README.md and dive into design rationale in docs/.

[ 05 / FAQ ]

ASCII and box-drawing questions

The questions people ask before drawing their first plain-text diagram.

? How do I make an ASCII diagram?

Describe the shapes in JSON and render them with monospace-cli, or open the interactive editor and draw them directly. Both produce plain text you can paste into a file, a Markdown fence or a terminal.

> Does it support Unicode box-drawing characters?

Yes. Nine glyph tables are built in, from ASCII fallbacks to light, heavy and double box-drawing characters, so the same diagram can render in whichever set the target medium displays.

# Can I embed the diagrams in Markdown?

Yes. The output is plain text, so it fits inside a fenced code block and keeps its layout in a monospaced renderer.

* Can I use it in scripts or CI?

Yes. monospace-cli is non-interactive: it reads a description and prints the picture, which makes it usable in a build step or a documentation pipeline.
